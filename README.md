# Alien Translation Project: Neural Machine Translation for Extraterrestrial Language

## Project Overview
This research project addresses the competitive machine translation task from the Yandex NLP training program, focusing on translating an extraterrestrial language into English. The core challenge involves developing a robust neural translation system without parallel validation data, requiring careful architectural design and data preprocessing strategies.

## Technical Implementation

### Data Pipeline
- **Source**: Competition dataset hosted at `https://disk.yandex.ru/d/u8mmcUBn64p_Nw`
- **Preprocessing Strategy**: Implemented a multi-stage filtering pipeline to address data quality issues:
  - Length-based filtering: Removed sentence pairs with character length ratios exceeding 2:1
  - Punctuation consistency: Eliminated pairs with mismatched question marks and exclamation points
  - Implementation details available in `prepare_data.ipynb`

### Model Architecture
- **Tokenizer Development**: Trained separate BPE tokenizers for source (alien) and target (English) languages using the `tokenizers` library, optimizing vocabulary sizes for each language's morphological characteristics
- **Core Model**: Transformer-based encoder-decoder architecture with causal masking in decoder layers
- **Configuration**: Complete hyperparameter specifications documented in `configs/config.yaml`, including attention mechanisms, layer configurations, and optimization parameters

## Experimental Results
- **Evaluation Metric**: BLEU score on private test set
- **Current Performance**: 0.56 BLEU, ranking 132/190 on the Yandex Contest leaderboard
- **Submission**: Predictions generated by the trained model are saved to `data/submission`

## Research Contributions
This project demonstrates practical applications of transformer architectures for low-resource translation scenarios, with particular attention to data quality challenges in competitive ML environments. The implementation balances model complexity with computational efficiency while maintaining competitive performance against other submissions.
